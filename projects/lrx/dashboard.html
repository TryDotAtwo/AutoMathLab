От отдельных лемм
к целому доказательству

Мы исследуем задачу дискретной математики: сколько движений понадобится, чтобы упорядочить любую перестановку? За один шаг можно сдвинуть весь ряд влево, вправо или поменять первые два элемента. Диаметр — число шагов для самого трудного случая при оптимальном решении.

diam(LRXₙ) = n(n − 1) / 2 · n ≥ 4

Математический текстВерхняя представлена рукописью с исправлениями; точная версия и проверки учитываются отдельно.
Формализация LeanНижняя и отдельные компоненты проверены. Полная безусловная верхняя ещё не замкнута.
ПубликацияИсходники, review и права распространения — отдельная очередь. Открытый PR ещё не main.

Что должно соединиться

Определения→ Подъём и фаза→ Допустимый план→ Исполнение + бюджет→ Верхняя+ Нижняя → Равенство

Главный стык: доказать, что подходящий план существует для каждой перестановки. «Любой допустимый план можно исполнить» само по себе этого не доказывает.

Основной маршрут и альтернатива C показаны раздельно. Multiset с нулями и среднее расстояние в другом графе не входят в процент покрытия этой теоремы. Процента доказательства здесь нет.

Как движется работа

Очередь → работа → независимая проверка → интеграция → готово. У каждого пакета есть точная приёмка. Предложенный исполнитель ещё не означает принятую задачу. После результата тимлид связывает его с обязательством, передаёт reviewer и предлагает следующий незанятый участок.
