Исправлены воспроизводимые ошибки:

- Фиктивные verification/evidence и пустые строки больше не разрешают done.
  Статус, охват и оговорки разделены; для готовности нужна запись с точной
  формулировкой, проверяющим и закреплёнными версиями артефакта и проверки.
- Готовность проверяется по выбранным зависимостям каждого узла, независимо
  от декоративной strategy. Условный EXEC может быть закончен раньше PLAN;
  безусловные U-ALL/EQ не могут скрывать предпосылки за build-only рёбрами.
  Проверенная альтернатива заменяет только перечисленные интерфейсы, остальные
  обязательства сохраняются. Текущий реестр альтернативу ещё не выбирает.
- Evidence/issue/record URL проверяются по одной политике. HTML также не
  создаёт активную ссылку для неподдерживаемой схемы.

Прежние подробные verification сохранены в notes. Для уже готовых D/LIFT
добавлены ссылки на сохранённые публичные материалы при точных commit PR5/PR7.
Авторская Lean-проверка LIFT не переименована в независимый replay.
