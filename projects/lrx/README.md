# LRX: постановка и карта материалов
## Основная цель
Текущий приоритет от научного руководителя (25 сентября): **верхняя граница завершена; перепроверить нижнюю**. Точная ссылка на доказательство U ещё закрепляется; это сообщение руководителя, не новый независимый review. Поиск верхней/multiset-моста выведен из активного плана.

Исходная задача — доказать diam(LRXₙ)=n(n−1)/2 для различных меток, с явной областью n≥4. Определения, две части доказательства и малые исключения приведены в [дорожной карте](ROADMAP.md). Текущая [доска пакетов](KANBAN.md) связывает исполнителей с проверяемыми выходами.

Ниже сохранена отдельная вспомогательная постановка; её результат не переносится на исходную задачу без специального доказательства.

## Модель с повторяющимися нулями
Состояние — строка из различных меток 1,…,m и r неразличимых нулей; n=m+r.
L циклически сдвигает строку влево, R — вправо, X меняет первые два символа.
Канонический корень: (1,…,m,0,…,0). Стоимость каждого движения — 1.
d(v) — минимальное число движений до этого фиксированного корня.
E_r(n)=max_v d(v) — эксцентриситет корня (радиус сортировки в этой постановке), не автоматически диаметр.

## Открытая гипотеза
Для m≥8, r≥2 обсуждается
E_r(n) ≤ m(m+1)/2 + (r−1)(m−2), где n=m+r.
При m=8 правая часть равна 6n−18.

Это перенесённая постановка исследовательской темы, а не доказанный результат. Перед использованием сверяйте конвенции с первичным пакетом. Метки 0-based/1-based, выбранный корень и факторизация по вращениям должны быть заданы явно.

## Рабочие направления
- Конструктивные слова и аффинные оценки для семейств нулевых блоков.
- Точные рациональные смеси, сертификаты и границы применимости конечного пула.
- Проверка спорных лемм с фиксацией определения портов/разрезов.
- Независимый BFS: reach, точные слои, эксцентриситет; диаметр требует отдельного обоснования.
- Lean-формализация и проверенная связь формальной модели с исполняемой программой.
- Сведение покрытий с общей нумерацией и проверкой пересечений.
