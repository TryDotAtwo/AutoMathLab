# Reproduce the completed B baseline

This directory preserves B's eight completed modules, 29 axiom reports and pinned environment. [Result and limitations](../2026-09-26-lrxavm2-scalar-enumeration-baseline.md).

## Lightweight integrity check

```sh
python3 verify.py
```

Expected: `Integrity PASS: 8 modules; 29 matching historical axiom reports. This is not a fresh Lean build.` No dependencies are downloaded. It checks the archive-extracted manifest, source/log hashes from the historical receipt, theorem/axiom report counts, allowed imports and absence of placeholder/native-proof constructs in the eight sources.

## Fresh kernel build with an existing pinned environment

```sh
python3 verify.py --build \
  --lean-bin /absolute/path/to/lean-4.34.0/bin \
  --packages /absolute/path/to/matching-project/.lake/packages \
  --output /absolute/path/to/new-verification-output
```

The output directory must not exist and must be outside this package. All dependency commits must match `formal/lake-manifest.json`. The command checks sources in a temporary copy, uses one Lean worker, saves new full logs and a new receipt, and leaves historical evidence untouched. It does not download anything. Requires Python 3, Git, Lean/Lake 4.34.0, pinned Mathlib and its compiled cache.

If you do not have the dependencies, provision them separately in a disposable copy of `formal/` using the included `lean-toolchain`, `lakefile.toml` and lock. Standard Lake dependency/cache setup requires network access and disk space; it is **not run by this PR or the lightweight verifier**. Do not update the lock to a newer Mathlib version and call it the same reproduction.
