# Пакет нижней границы, 25 сентября 2026

Начните с [карточки результата](../2026-09-25-lrx-agents-lower-bound.md), затем PROOF_B_V3_RU.md и review координатора. B-v3 сохранён побайтно; его фраза «ожидает review» описывает момент создания, актуальный вердикт записан отдельно.

A-review и аудит сохранены как исходные записи. Упоминания других рабочих файлов относятся к установке A; этот компактный пакет не выдаёт их за включённые Lean-исходники. `manifest.json` фиксирует каждый включённый файл, кроме самого manifest.

Быстрая диагностика: `python3 check_folded_transport.py` (стандартная библиотека Python3). Успех — конечная проверка тождеств, не универсальное доказательство.
