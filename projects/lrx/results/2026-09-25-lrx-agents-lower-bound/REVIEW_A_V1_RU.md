## 1. Один шаг и полный обход

Пусть `0≤c,z<j`, `h∈Z`, `F(z,c,h)=z−[z>c]+h`. Для X на `c<j−1` имеем `F(c,c,h)=F(c+1,c,h)=c+h`: две меняющиеся метки сохраняют свои координаты; остальные не двигаются. Для внутреннего L разность равна `[z=c+1]`. При L через разрез `c=j−1 → 0, h→h+1` разность равна `1−[z>0]=[z=0]`. Для R это обратные равенства. Различность всех j меток гарантирует, что меняется ровно одна координата, на единицу. Тем самым L1-длина каждого шага равна 1 для L/R и 0 для разрешённого X. Телескопирование и неравенство треугольника дают предел на каждом отрезке, независимо от winding.

Гипотеза о запрете X на O необходима: обмен позиций j−1 и 0 вообще не сохраняет F. В доказательстве двух дуг O является разрезом блока; ни один разрешённый одноцветный X через него не проходит. В случае j=2 L/R могут иметь одинаковые курсорные остатки, но противоположные изменения h/F; их нельзя отождествлять. Аргумент B этого не делает.

## 2. Отражённые внутренние endpoints

При `v=j−2−u` имеем `[j−1−x>v]=[x≤u]=1−[x>u]`. Поэтому начальный `Z_x=x−[x>u]`, конечный `F_x=j−2−Z_x+h`, и их сумма действительно постоянна по x. Для внешних endpoints оба индикатора нулевые; константа вместо j−2 равна j−1. Смешивать эти случаи нельзя; B разделяет их корректно.

## 3. Внешняя точка и геометрическая оценка

В посещении O промежуточный вектор равен `P_x+h0`, где P — перестановка всех j позиций. Стоимости двух частей слова складываются без перекрытия; X в самой точке разреза недопустим. Покоординатно применяем `|A|+|B|≥|A−B|`. Начальный Z сокращается, остаётся `|2P_x+2h0−j+2−h|`. Для любого t сумма `|2i−t|`, `0≤i<j`, не меньше `2k(j−k)` при `k=floor(j/2)`: спарить i с j−1−i, i<k. Неспаренный центр при нечётном j неотрицателен. Это равно floor(j²/2). Никакого предположения о P, кроме перестановочности, или о числе обходов нет.

## 4. Проекция именно оплаченного слова

Дам явную проекцию поднятого курсора, чтобы исключить бесплатную смену фазы. Для A=[0,a−1], n=a+b и `C=nh+c`, `0≤c<n`, положим

`Q_A(C)=ah+min(c,a−1)`.

Её остаток по a — исходное ребро c, если c≤a−2, и O_A=a−1 иначе. При L разность Q_A равна 1 ровно при пересечении позиции A (включая переход n−1→0); иначе 0. R — обратный шаг. Для B применим ту же формулу с j=b к `C−a`. Тогда `Q_A(C)+Q_B(C)=C−1`, что также проверяет разбиение подписанных движений. Для ненаправленной цены каждый исходный L/R входит ровно в одну проекцию со своей исходной буквой. Поэтому r=r_A+r_B буквально, а не лишь неравенство расстояний.

Позиционные массивы проекций — ограничения физического массива на соответствующую дугу. Свой X сохраняется как соседняя транспозиция при внутреннем курсоре; чужой X и нулевые курсорные движения удаляются. Состояния при удалённых шагах в своей проекции неизменны. Получаем настоящие локальные трассы, включая произвольные повторы X, а не независимые оптимальные слова. Начальное локальное h можно обнулить общей трансляцией F; конечное h остаётся произвольным.

## 5. Курсорные условия, waypoint и минимальные блоки

Общее отражение ребра `J(c)=a−2−c mod n` сохраняет каждое множество внутренних рёбер. Для B после c=a+t оно даёт t'=b−2−t mod n. Два граничных ребра a−1,n−1 переставляются. Поэтому внешние endpoints переходят в O,O, внутренние — в u,j−2−u. Если они внутренние, полное обращение другого блока длины≥2 требует хотя бы одного X в нём: одни вращения не меняют физические позиции. В этот момент своя проекция находится в O. При a=2 или b=2 этот довод сохраняется: есть единственное внутреннее ребро и обязательный X. Внешний случай не требует отдельного waypoint.

Это и объясняет, почему прежний контрпример к сумме независимых проекционных минимумов не опровергает новую лемму: независимые минимизаторы не обязаны посещать O. Новое ограничение следует из общего платного слова.

## 6. Поправка при двух нечётных размерах

При a,b нечётных n чётно, а `v−u ≡ a−2−2u (mod n)` нечётно. Для произвольного слова r≡#L−#R≡v−u (mod2), поскольку X курсор не двигает. Следовательно r нечётно. Каждое `floor(j²/2)` для нечётного j чётно (j²≡1 mod8), так что сумму двух оценок нужно увеличить минимум на 1. Это не использует минимальность числа X. Получаем `r≥floor((a²+b²)/2)=M+floor(n/2)≥ab` для всех a,b≥2. Без поправки оценка действительно была бы на единицу недостаточной при равных нечётных размерах.

## 7. Произвольное слово

Можно выбрать кратчайшее слово: тогда A уже Lean-проверил отсутствие повторного обмена пары, точную пару/цветовую чётность и обязательные одноцветные обмены. Альтернативная итеративная редукция B тоже корректна: между двумя X той же фактической пары позиционное действие сохраняет множество {0,1}, коммутирует с X, и оба X удаляются. После удаления пары пересчитываются, длина уменьшается на 2. Не требуется, чтобы другие пары сохранялись от прохода к проходу.

Цвета физических позиций неизменны. Метки разных компонент одного цвета не могут встретиться, хотя их обмен обязателен, значит каждый из двух непустых цветов — одна дуга. Внутри дуги каждая пара меняет относительный порядок ровно один раз, поэтому финал — полное обращение. При начале дуги e нормировка даёт u=−e; физический финал q(t)=a−1−t, видимый целевой список u+1−i, отсюда v=a−2−u. Эта фазовая связь точна.

Пустой класс требует N букв X. Для singleton-класса M=C(n−1,2), соседние XX невозможны, длина≥2M−1. Разность с N равна (n−1)(n−4)/2−1, положительна при n≥5. При n=4 имеем ≥5, и чётность целевой перестановки против нечётности каждой буквы округляет до6. Для остальных случаев |w|=M+r≥M+ab=N. Удаления только укорачивали исходное слово. Следовательно аргумент распространяется на все слова к p*, и D_n≥N для всех n≥4.
