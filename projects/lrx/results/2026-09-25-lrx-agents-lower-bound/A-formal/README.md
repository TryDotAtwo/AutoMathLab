# Формальные исходники и свидетельства A

Автор — исследователь A. Скопированы19 исходников точного локального импортного замыкания, закреплённые Lean4.34.0/mathlib,19 журналов компиляции и BUILD_RESULT.json. Хеш каждого исходника и журнала координатор сверил с receipt перед копированием. Бинарные .olean и внешние библиотеки не включены. Исходники из Cycle11 здесь являются зависимостями, а не возобновлением старой научной задачи.

A выполнил чистую сборку локальных модулей25сентября08:48UTC, переиспользуя закреплённые внешние объекты Mathlib. Точные команды, порядок модулей, SHA исходников/логов и аксиомы сохранены в evidence/BUILD_RESULT.json. Это не сборка всего Mathlib с пустым кешем. Координатор проверил свидетельства, но не запускал Lean повторно.

Для новой машины с Elan нужно восстановить зависимости из formal/lake-manifest.json и установить указанный lean-toolchain. Предлагаемые команды из formal/: `lake exe cache get`, затем `lake build LRX.LowerBoundSwapBudget LRX.LowerBoundCyclicContiguity LRX.LowerBoundTwistedRebase LRX.LowerBoundPotentialBarrier LRX.LowerBoundProjectionBarrier`. Это инструкция для отдельного воспроизведения; новый запуск этих команд координатором не заявляется. Фактически выполненные A команды доступны в receipt, а воспроизведение требует сохранения закреплённых версий.

Главное ядро: LRX.LowerBoundSwapBudget.physical_two_block_total_lower. Оно доказывает нижнюю длины физической двухблочной трассы. Формальная структурная часть до круговой связности проверена отдельно. Мост исходного native-слова→PhysicalTrace и сборка классов0/1 не соединены в единую конечную теорему. Поэтому полного formally-checked статуса исходному Dₙ≥N этот пакет не присваивает. Аксиомы75 LB-экспортов: только propext, Classical.choice, Quot.sound по сохранённым журналам.
