# LRX: дорожная карта к доказательству

Автор организации: Codex-координатор по запросу Aleksei Makin. Дата: 2026-09-25. Это план исследования, не новый математический результат.

## Основная цель

Для строки из n различных меток 1,…,n допускаются три хода стоимости 1:

- L(a₁,…,aₙ)=(a₂,…,aₙ,a₁);
- R(a₁,…,aₙ)=(aₙ,a₁,…,aₙ₋₁), то есть L⁻¹;
- X(a₁,a₂,a₃,…,aₙ)=(a₂,a₁,a₃,…,aₙ).

Вершины — перестановки; ребро — один такой ход. Расстояние — длина кратчайшего слова. Проверяемая основная гипотеза: **diam(LRXₙ)=n(n−1)/2 для n≥4**. Граница n≥4 требует явного указания: при n=3 граф имеет диаметр 2, а формула даёт 3 (все элементы S₃ представлены словами длины ≤2: e,L,R,X,LX,RX). Для n=1,2 значения разбираются отдельно.

## Текущий приоритет — перепроверка нижней границы

Обновление 25 сентября 2026 по поручению владельца, передающего решение научного руководителя: **верхняя граница уже доказана; активная задача — перепроверить нижнюю**.

- **U:** diam(LRXₙ)≤N, N=n(n−1)/2. Организационный статус: завершено по сообщению научного руководителя; не повторять поиск доказательства. Точный первичный пакет, версия и область ещё должны быть привязаны к реестру. В доступном координатору журнале через сообщение2511 общий источник не найден; независимая проверка здесь не заявляется.
- **D:** для каждого n≥4 предъявлено pₙ с d(e,pₙ)≥N. Активный приоритет: аудит существующего доказательства, всех путей, чётностей и баз. Сначала закрепить его источник; отсутствие файла не заменять догадкой о содержании.
- **Интеграция:** сопоставить проверенную D с точной U по графу, метрике и области n. Доказательность утверждения и статус независимой проверки сохраняются раздельно.

Перенумерация различных меток сохраняет генераторы и переводит любой корень в любой другой: эксцентриситет тождества равен диаметру. Для multiset этот аргумент автоматически не применяется. Ограничение конечного каталога слов, неудача построителя и цена конкретного маршрута не являются нижней границей расстояния.

## Закреплённый источник D

Первый агент нашёл [G. V. Antiufeev, arXiv:2601.08715v3, 4 июня 2026](https://arxiv.org/html/2601.08715v3): нижняя граница заявлена в теореме2, зависимости включают лемму1 и теорему1. Координатор открыл первичный источник и подтвердил постановку. В прежнем обосновании остался пробел совместной стоимости; A/B построили новый общий аргумент. [PR5](https://github.com/TryDotAtwo/AutoMathLab/pull/5) содержит B-v3 и отдельные ИИ-review A/координатора. Прежнее доказательство не объявляется проверенным дословно. Человеческая рецензия новой полной цепочки ещё нужна.

## Итог первого окна и следующая очередь

Нижняя d(e,(2,1,n,…,3))≥N дляn≥4 получила полное аналитическое доказательство и два независимых ИИ-review. [ПакетPR5](https://github.com/TryDotAtwo/AutoMathLab/pull/5), commit388935c, закреплён SHA исходного текста. Статус claimed / independently-reproduced; это не human review. Lean-ядро физической двухблочной модели не объявляется полной формализацией исходного Cayley-графа.

A/B завершают сохранение пакетов без новых расширений. Координаторская проверка семи аналитических звеньев выполнена. Активный остаток: человеческая рецензия нижней и закрепление первичной U тимлидом; затем сверка U+D. Новый тяжёлый BFS и поиск верхней не нужны. Формальное соединение native→PhysicalTrace и классов0/1 — ограниченное следующее предложение, не автоматически запущенная задача.

## Сохранённые вспомогательные направления

Прежние M3 (поиск верхней), M5 (multiset-мост) и оптимизация коэффициентов исключены из активного критического пути. Уже полученные результаты, исходники и handoff сохраняются. Возобновлять их только при конкретном дефекте исходного доказательства или отдельном поручении руководителя; отсутствие источника само по себе не поручает заново доказывать U.

[Multiset-постановка](README.md#multiset), импорт [#1](https://github.com/TryDotAtwo/AutoMathLab/issues/1) и конечный BFS [PR #2](https://github.com/TryDotAtwo/AutoMathLab/pull/2) сохраняют самостоятельный статус. Они не заменяют общую нижнюю границу исходного графа.

## Критерий завершения

Версионное доказательство D проверено для всей указанной области, все зависимости перечислены, устранены либо явно оставлены обнаруженные пробелы; затем отдельный review объединения U+D. Ни конечный BFS, ни завершённый рабочий пакет не означают автоматически доказательство всей гипотезы.
